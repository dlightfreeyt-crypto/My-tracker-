MY DAY – Android Website Shortcut / PWA

Is app ko Android phone se home screen par add karne ke liye:
1. Is project ko HTTPS hosting par publish karna hoga (GitHub Pages jaise free hosting).
2. Publish hone ke baad Chrome mein website URL kholo.
3. Chrome ke 3 dots (⋮) > Add to Home screen / Install app chuno.
4. MY DAY icon home screen par aa jayega.
5. Pehli baar online kholne ke baad app offline bhi kaam karega.

GitHub Pages se free publish karne ke liye:
- github.com par sign in karke new public repository banao, e.g. my-day-tracker.
- Is ZIP ke andar ki files/folders repository ke root mein upload karo.
- Repository Settings > Pages > Deploy from a branch > main / root > Save.
- Pages URL kholkar Chrome mein Add to Home screen karo.

Data browser ke local storage mein save hota hai. Browser data clear karne ya app data delete karne se history mit sakti hai. History usi phone/browser par rahegi.
